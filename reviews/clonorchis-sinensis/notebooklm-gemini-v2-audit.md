## 一、结论先行

v2比v1明显进步：它开始使用稳定的`claim_id`，并尝试为每条命题附来源、
定位、证据类型和不确定性。但是，这10条还不能原样进入正式知识层：

- 2条可保留核心内容，但必须补齐原来源定位；
- 7条需要拆分、缩小范围或纠正证据类型；
- 1条只能保留一般性的One Health方向，所列具体制度工具没有证据；
- 10条的“不确定性：低”均未同时满足“内容低不确定＋来源已解析＋定位可复核”。

最严重的追溯错误是`C_CS_005`引用的`D0051`：题库原行实际讨论
**卫氏并殖吸虫**经溪蟹、蝲蛄感染，不是华支睾吸虫。

## 二、双轴判定

本审计不再用单一“正确/错误”掩盖证据问题，而是分别评价两个轴：

| 轴 | 可用值 | 含义 |
|---|---|---|
| `content_status` | PASS / REVISE / REJECT | 命题内容本身是否准确、原子和不过度 |
| `traceability_status` | RESOLVED / PARTIAL / BLOCKED | 声称的原文件和定位能否回跳复核 |

只有`content_status: PASS`且`traceability_status: RESOLVED`的原子命题，
才有资格在教师审核后进入正式知识层。

## 五、题库定位审计

### 5.1 题号不是全局唯一定位

14个被引用的`D`编号在汇总文件中对应30行。重复情况如下：

| 去重ID | 命中行数 | 备注 |
|---|---:|---|
| D0019 | 4 | 跨中医班、护理班和不同作业 |
| D0020 | 4 | 跨中医班、护理班和不同作业 |
| D0048 / D0049 / D0050 / D0081 / D0051 | 各3 | 多为同题复制到不同班级或题目文件 |
| D0383 / D0404 / D0411 / D0417 / D0422 / D0522 / D0700 | 各1 | 仍须保留来源文件和文件内题号 |

从现在起，题库证据定位必须至少包含：

```text
来源文件 + 来源工作表 + 题号_文件内 + 去重ID
```

例如：

```text
26年秋第三次作业（中医班）.xls
  / 课程题库 / 文件内题号2 / D0049
```

### 5.2 关键错引

`D0051`的三条重复记录均为：

> 卫氏并殖吸虫感染人体的主要方式是生食或半生食溪蟹、蝲蛄。

它不能证明`C_CS_005`。这是“题号看似存在，但指向了另一寄生虫”的实体错配，
必须在正式抽取前拦截。

### 5.3 题库不能升级为事实来源

`D0522`和`D0411`的题干及解析直接声称“批次追溯＋抽检公示＋生食零容忍”
比宣教更有效，但未附比较研究、政策评估或规范来源。它们只能说明课程中曾这样
命题，不能证明干预效果。

## 八、给学生的逻辑训练嵌入方式

不要求学生先学完形式逻辑，但要求每条关系经过四个强制字段：

1. `statement_type`：事实、风险、诊断线索、诊断证据、机制或干预；
2. `scope`：物种、宿主、地区、时间和条件；
3. `modality`：是“必然”“可能”“增加风险”还是“建议”；
4. `evidence_role`：该来源是在证明事实、展示课堂表达，还是仅说明曾经考过。

这样可以把逻辑训练嵌入知识图谱编辑本身：学生无法只凭一句“看起来正确”的话
越过类别、条件和证据边界。
