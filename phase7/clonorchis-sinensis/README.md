形成学习通材料草案。

## 完成内容

- 36条原子命题：30条关系、6条结构化叙述；
- 17个PCMS新增实体；
- 3份既有实体的批次化关系扩展；

- 16项固定回归全部通过；
- 学习通任务稿、学生说明和教师监督SOP均为未发布草案。
