# 学生使用说明（草案）

状态：**未发布**

## 你将使用什么

你将使用一个经过教师审核的华支睾吸虫最小知识集。知识图谱把实体和关系明确连接；RAG会先检索这个知识集，再生成回答。

## 如何判断回答是否可靠

每次阅读AI回答时，请检查四件事：

1. **事实准确**：名称、阶段、宿主、诊断或治疗关系是否与材料一致；
2. **边界清楚**：回答是否承认资料未覆盖的部分，是否避免“必然、唯一、所有地区都有效”等扩大表述；
3. **关系合理**：能否说清“谁—通过什么关系—连接到谁”，而不是只堆知识点；
4. **容易理解**：结论是否直接、层次是否清楚、术语是否得到必要解释。

## 0—2分的自查方式

- `2分`：准确、完整，且没有越过证据边界；
- `1分`：核心方向正确，但缺少重要限定、关系或解释；
- `0分`：核心结论错误、答非所问，或用资料外内容替代当前证据。

## 必须停下来核查的情况

- 把囊蚴和成虫的角色混在一起；
- 仅凭暴露史或影像宣布确诊；
- 把阿苯达唑说成WHO当前推荐药物；
- 把IARC Group 1解释为感染者必然患癌；
- 声称某套One Health措施能在所有地区彻底消除疾病；
- 给出当前材料没有来源的数字、药物方案或食品处理参数。

## 数据与安全

不要在AI对话中提交姓名、学号、联系方式、病历或其他个人信息。该工具只用于课程学习，不替代临床判断。
