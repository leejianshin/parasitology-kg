# 华支睾吸虫学习通试点教师监督SOP（草案）

状态：**仅供教师准备，未授权发布**

## 1. 角色

- 课程负责人：最终内容、发布和暂停决定；
- 陈海英老师：协作复核，当前状态为待补；
- 学生：学期开始并获得正式通知后，才进入学习任务。

在陈海英老师尚未反馈时，不得把材料写成“两位教师共同批准”。

## 2. 发布前检查

1. 确认PCMS版本、实体数、关系数和回归报告一致；
2. 确认学生版不含教师评分细则、答案、私有审计文件或原始模型推理；
3. 确认学习通任务不要求学生提供个人敏感信息；
4. 抽查感染阶段/致病阶段、诊断线索/确证、危害/风险、推荐/替代四组边界；
5. 取得课程负责人的单独发布授权。

## 3. 课堂监督

教师不只看最终答案，还要观察学生是否：

- 回查实体、关系和来源；
- 对资料缺口明确拒答或保留；
- 能指出AI回答遗漏的限定；
- 能用完整关系说明One Health传播机制。

## 4. 评分记录

四个维度分别按`0、1、2分`记录：

- 事实准确；
- 证据边界；
- 关系推理；
- 学生可理解性。

原始逐人评分、名单和个体回答仅保存于学校授权的私有位置，不进入公共GitHub。公共仓库最多保存去标识化汇总、方法和规则。

## 5. 主要硬失败

出现以下任一情况，应标记硬失败并暂停把该回答作为学习支撑：

- 关键医学事实与正式知识层相反；
- 伪造来源、实体ID或关系ID；
- 应拒答时用模型常识补齐；
- 把辅助线索当作确诊；
- 给出未经授权的个体化处方；
- 把致癌危害分类写成个体必然患癌；
- 暴露学生个人数据或原始评分。

## 6. 纠错与暂停

1. 保存问题编号和去标识化错误描述；
2. 判断缺陷属于知识缺口、Schema缺口、检索缺陷还是生成约束缺陷；
3. 在私有审计区完成修订和回归；
4. 由课程负责人决定继续、限制范围或暂停；
5. 未通过回归的修订不得直接覆盖学生使用版本。

## 7. 试点结束后的最低输出

- 去标识化完成率和评分汇总；
- 常见错误类型；
- RAG相对无检索回答的变化；
- 知识缺口和Schema缺口清单；
- 下一批知识扩展建议。

本SOP不证明教学效果；真实效果须在学生实际参与后按预先确定的方法评估。
