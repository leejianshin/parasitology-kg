# 华支睾吸虫知识图谱学习通任务稿（草案）

状态：**教师准备稿，未向学生发布**
适用对象：下学期临床医学班
知识范围：`clonorchis_pcms_v1`
预计形式：课前理解—课中核查—课后应用

## 一、学习目标

完成任务后，学生应能：

1. 按顺序说明华支睾吸虫主要生活史阶段及必要宿主条件；
2. 区分感染阶段、主要致病阶段、诊断线索和病原学确证证据；
3. 解释人、动物、淡水环境、螺和鱼在传播机制中的具体连接；
4. 使用知识图谱或RAG回答时主动核对来源和证据边界；
5. 对语料未覆盖的问题明确说明不足，不用模型常识补齐。

## 二、任务流程

### 课前：建立最小框架

阅读教师发布的华支睾吸虫PCMS材料，完成生活史阶段排序和宿主角色匹配。学生需为每个判断保留对应关系或来源定位。

### 课中：核查AI回答

教师提供若干AI回答。学生按以下顺序判断：

1. 回答是否命中题目；
2. 主体、关系和客体是否正确；
3. 是否混淆感染阶段与致病阶段；
4. 是否把诊断线索写成确诊；
5. 是否把危害分类写成个体必然患癌；
6. 是否越过当前知识集补写未登记内容。

### 课后：病例与One Health应用

围绕病例暴露史、病原学检查和传播环节，提交一份短答。短答必须把“已有证据”和“当前知识缺口”分开写。

## 三、建议提交格式

```text
结论：
使用的实体或关系：
依据来源或定位：
不能由当前材料推出的内容：
```

## 四、教师发布前门槛

- PCMS正式图和派生材料回归测试通过；
- 学习通页面只导入批准的学生版内容；
- 陈海英老师协作复核状态如实显示，不将“待补”写成共同批准；
- 学生名单和个人数据只在学校授权系统内处理；
- 课程负责人另行给出“可以发布”授权。

## 五、边界

本任务是学习和证据核查活动，不提供个体化诊断、治疗或处方建议。当前草案不构成学生发布授权。
