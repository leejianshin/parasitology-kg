# 项目范围与原则

## 1. 正式定位

`parasitology-kg` 是一个面向人体寄生虫学学习的、以 One Health 为总体关系框架、支持 RAG 应用的开放知识图谱。

项目首先服务于学生的补充学习：学生可以将仓库内容接入支持文件、GitHub 或知识库检索的 AI 工具，在教材和课堂之外获得有来源、可追溯的解释与关系查询。

## 2. 第一目标

第一目标不是建设网站，也不是批量转换课件，而是建立一个可持续扩展的知识图谱生产与审核流程，并用华支睾吸虫完成首个端到端试点。

华支睾吸虫试点应能够支撑以下问题：

1. 完整解释生活史及各宿主的不同角色；
2. 区分感染阶段、致病阶段和诊断阶段；
3. 解释人类行为、动物宿主和淡水环境如何共同参与传播；
4. 分别说明人、动物、环境和食品链层面的防控措施；
5. 为关键事实返回明确来源，而不是只给出无出处结论。

## 3. One Health 组织框架

One Health 不是附加标签，而是知识结构的组织原则。知识图谱应同时表达四类关系：

### 3.1 人类健康

感染、寄生部位、致病机制、临床表现、诊断、治疗、人群行为和健康教育。

### 3.2 动物健康

终宿主、中间宿主、保虫宿主、动物感染、宿主范围及其在传播中的角色。

### 3.3 环境健康

水体、土壤、气候、生态系统、粪污、养殖环境和媒介孳生环境等传播条件。

### 3.4 跨域治理

食品安全、养殖管理、环境卫生、动物管理、人群筛查治疗及多部门协作。

不得为了体现 One Health 而添加来源不支持的因果关系。生态关联、传播机制和治理建议应分别表达。

## 4. 知识层级

项目中的内容分为四层：

| 层级 | 内容 | 是否可作为正式RAG依据 |
|---|---|---|
| 原始来源 | 教材、课件、教学大纲、题库、论文和规范 | 需登记，不直接公开全文 |
| 候选提取 | NotebookLM、Gemini或其他工具生成的提取结果 | 否 |
| 审核知识 | 经过来源核对和人工审核的结构化Markdown | 是，属于权威主数据 |
| 派生数据 | 从审核知识生成的CSV、JSON或图数据库导入文件 | 是，但不得手工脱离主数据维护 |

## 5. 来源角色

不同来源承担不同功能，不简单混合：

- 教材和规范：用于核心事实、术语和基础关系；
- 教师课件：用于实际教学重点、表达顺序和案例选择；
- 教学大纲：用于专业、学时和教学目标边界；
- 题库与学情材料：用于易错点和学习支持；
- 同行评议论文与权威机构资料：用于更新知识和 One Health 扩展；
- AI提取结果：仅用于提高整理效率，不构成独立证据。

同一结论被多个 AI 输出重复，不视为多条独立证据。

## 6. 审核权责

- AI工具可以提取、拆分、比较和格式化；
- 项目维护者负责来源核对、关系命名和技术校验；
- 学科教师负责最终事实口径、教学适切性和发布批准；
- 未经批准的内容只能留在工作区或分支中，不能进入正式知识层。

## 7. 明确不做

第一阶段不做以下事项：

- 不搭建 Quartz、GitHub Pages 或其他展示网站；
- 不批量导入全部课件和教材；
- 不把普通双向链接图直接等同于正式知识图谱；
- 不上传受版权保护的教材和课件全文；
- 不以AI输出自动替代教师审核；
- 不提供个体诊断、处方或临床决策。

## 8. 首轮成功标准

华支睾吸虫试点只有同时满足以下条件才算成功：

- 实体、关系和来源字段可被机器稳定解析；
- 关键关系具有来源或证据指向；
- Markdown正文能够独立支持语义RAG；
- 图关系能够回答跨实体查询；
- 预设正确问题和陷阱问题均通过测试；
- 教师完成最终审核并批准进入主分支。
