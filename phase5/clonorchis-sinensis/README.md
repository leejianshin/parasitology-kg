# Phase 5：华支睾吸虫正式准入

本阶段把Phase 4的39条原子候选重新判断为关系、限定、叙述或研究层证据，并按风险分批写入正式知识目录。

## 四类重分

| 类别 | 数量 | 用途 |
|---|---:|---|
| 可建边 | 21 | 主客体和关系类型均可进入现有Schema |
| 仅作限定 | 6 | 只限制地区、频率、严重度或证据权重 |
| 仅作叙述 | 7 | 解释诊断边界或食品安全背景，不生成关系 |
| 研究层保留 | 5 | 保留特定地区和研究设计语境，不进入当前正式关系层 |

机器可核对的完整清单见[准入方案](admission-plan.yml)。

## 第一批

第一批选择10条关系，覆盖核心感染行为、寄生部位、病理分布、诊断线索、临床频率和One Health基础干预：

| 原子命题 | 主语 | 关系 | 宾语 |
|---|---|---|---|
| W2-ATOM-001 | 华支睾吸虫病 | 具有诊断线索 | 生食或未充分加热淡水鱼 |
| W2-ATOM-005 | 华支睾吸虫 | 可通过其传播或获得感染 | 生食或未充分加热淡水鱼 |
| W2-ATOM-006 | 华支睾吸虫病 | 可通过其防控 | 避免食用生或未充分加热淡水鱼 |
| W2-ATOM-008 | 华支睾吸虫成虫 | 寄生于 | 肝内小、中型胆管 |
| W2-ATOM-009 | 华支睾吸虫感染相关胆道病理改变 | 发生于 | 胆道系统 |
| W2-ATOM-022 | 华支睾吸虫病 | 表现为 | 轻虫负荷感染无明显症状 |
| W2-ATOM-023 | 华支睾吸虫病 | 具有诊断线索 | 胆道影像学检查 |
| W2-ATOM-026 | 华支睾吸虫病 | 可通过其防控 | 改善卫生设施 |
| W2-ATOM-027 | 减少人粪便污染淡水环境 | 针对 | 淡水环境 |
| W2-ATOM-028 | 减少动物粪便污染淡水环境 | 针对 | 淡水环境 |

其中有四项结构化规范化需要教师特别核对：

- W2-ATOM-001与006按Schema统一了关系方向；
- W2-ATOM-023由候选中的`diagnosed_by`改为`has_diagnostic_clue`，因为影像不能单独确诊；
- W2-ATOM-027与028只用`targets`表达作用环节，并标记为受限推断，不声称量化效果。

## 暂不进入第一批

- 并发症因果与胆石形成机制；
- 淡水虾的宿主关系及其相对权重；
- 地区性干预研究效果；
- 具体食品处理参数；
- 教学、课程和题库元数据。

## 审核门

第一批14个实体及10条关系均标记为`in_review`。教师批准并合并前：

- 不改为`reviewed`；
- 不进入学生RAG；
- 不启动第二、三批正式写入。
