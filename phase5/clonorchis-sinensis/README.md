# Phase 5：华支睾吸虫正式准入

本阶段把Phase 4的39条原子候选重新判断为关系、限定、叙述或研究层证据，并按风险分批写入正式知识目录。

## 四类重分

| 类别 | 数量 | 用途 |
|---|---:|---|
| 可建边 | 21 | 主客体和关系类型均可进入现有Schema |
| 仅作限定 | 6 | 只限制地区、频率、严重度或证据权重 |
| 仅作叙述 | 7 | 解释诊断边界或食品安全背景，不生成关系 |
| 研究层保留 | 5 | 保留特定地区和研究设计语境，不进入当前正式关系层 |

机器可核对的完整清单见[准入方案](admission-plan.yml)。
