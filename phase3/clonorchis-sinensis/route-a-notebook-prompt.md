# 路线A：NotebookLM/Gemini固定提取Prompt

## 使用前设置

在Notebook中只勾选下列9个冻结来源。若权威网页尚未加入Notebook，应先以原URL
加入；不要选择第五版教材、其他第三讲课件、张巧玲论文或任何未登记来源。

来源及范围以`extraction-contract.yml`为准。

## Prompt

你正在执行华支睾吸虫知识图谱Phase 3路线A候选提取。

本次不是总结教材，不是生成教学文章，也不是回答医学问题。你只能从指定的9个
冻结来源及限定范围中抽取可追溯的原子命题。不得复用本Notebook此前生成的候选、
自检结论或对话答案，也不得调用未勾选来源。

首先输出`source_manifest`，逐一列出9个`source_id`、实际显示的来源标题、
是否可访问、是否能确认限定范围和观察到的定位。只要有一个必需来源不可访问、
标题不匹配或范围无法确认，就输出：

```yaml
source_manifest:
  status: FAIL
```

随后列出问题并停止，不得继续抽取事实。

全部来源通过后，严格按照`candidate-template.yml`输出。规则如下：

1. 每条命题只有一个主语—关系—宾语判断；出现两个独立判断必须拆分。
2. 不预设需要多少条；无直接证据的类别可以为空，不为完整性而补写。
3. 教材、正式权威网页或合格研究证据可以支撑相应事实；题库只记录考点，
   课件主要记录教学表达，两者不得单独证明医学事实、最新诊疗或干预效果。
4. 每条命题至少给出一个稳定定位：数字印刷页码、PDF页序、章节条款或完整URL。
5. 不把“来源无法提取”“系统未找到正文”等质控信息写成医学命题。
6. 明确区分感染阶段与致病阶段、诊断依据与辅助线索、危险因素与必然因果、
   防控原则与干预效果。
7. One Health关系必须由来源实际支持；不得为了形成闭环而补写因果箭头。
8. 不复制长段原文。`evidence_basis`只写简短释义和定位。
9. 题库只提供`dedup_id`；其他复合定位字段不得猜测，留空并标记`partial`。
10. 所有内容均为候选，不得标记为正式批准或已入库。

最后独立输出：

- `source_quality`
- `omissions`
- `conflicts`
- `schema_issues`
- `quality_check`

自检必须按实际输出计算。不存在某类命题时填`NOT_APPLICABLE`，不得为了得到
全PASS而改变判定。
